Langi Engine

Langi Engine is a lightweight, browser-based tool for worldbuilding and organizing ideas visually.

Create nodes for characters, locations, lore, factions, abilities, quests, and more, then connect them together on the canvas.

Getting Started
Open langengi.html in a modern web browser.
Use Shift + A or the Add Node button to create your first node.
Select a node to edit its information in the Inspector.
Drag from a blue output point to a red input point to connect nodes.
Use the Assets tab to manage images and other project media.
Use the Database and Timeline tabs to organize your project in different ways.

Projects are saved automatically in your browser, and you can export/import project data when needed.

Main Features
Visual node-based canvas
Node connections and groups
Project Navigator
Databases and Timeline
Image assets and basic image editing
Tables, graphs, and images inside nodes
Minimap and canvas customization
Autosave and project export/import
Fullscreen mode
